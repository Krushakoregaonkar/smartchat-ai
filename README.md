# SmartChat AI 🤖

SmartChat AI is an AI-powered chatbot website designed to provide intelligent, helpful, and interactive responses to user questions.

## ✨ Features

- AI-powered conversations using Groq API
- Real-time question and answer generation
- Conversation context within the current chat
- New Chat functionality
- Markdown formatting and table support
- Copy AI responses
- Loading and error handling
- Responsive chatbot interface
- Clean mint-green and teal user interface

## 🛠️ Technologies Used

- Next.js
- React.js
- Tailwind CSS
- JavaScript
- Groq API
- React Markdown
- Lucide React

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Krushakoregaonkar/smartchat-ai.git
```

### 2. Open the project folder

```bash
cd smartchat-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the API key

Create a `.env.local` file in the root directory.

Add:

```env
GROQ_API_KEY=your_groq_api_key
```

Replace the placeholder with your own Groq API key.

### 5. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## 🔐 Security

- API keys are stored in environment variables.
- Never upload `.env.local` to GitHub.
- Never expose your API key publicly.
